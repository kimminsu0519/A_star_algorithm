Heuristic Cost Function
f(n) = g(n) + h(n)
  • g(n): 출발 노드에서 현재 노드까지의 최단 이동 비용 (직선 10, 대각선 14)
  • h(n): 현재 노드에서 목표 노드까지의 예상 이동 비용 (대각선 제외 가로/세로 이동거리 × 10)
  • f(n): 총 이동 비용 f(n) = g(n) + h(n). 열린 목록 중 f(n)이 가장 작은 노드를 우선 선택
  • 화살표(Pointer): 부모 노드(Parent node)를 가리켜, 목표 노드 도착 시 시작 노드까지 거슬러 올라가 최단 경로 도출
